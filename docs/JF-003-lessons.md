# JF-003 课堂记录与可编辑时间轴

## 使用

顶部“课堂”进入：选择班级和月份，默认以圆圈显示课堂净分。点击可看全班和各组的加分、扣分、净分。
“编辑时间轴”显示所选北京日期内全部记分；横向滚动全天、拖动两侧边界，或直接输入精确时间。
预览调整前后净分，确认后保存归属。重叠、拆分全班批次、过期版本均禁止保存。
支持手动补建无记分课堂、设置状态、拆分、合并下一节。存在未归属有效记录时明确提示。
跨月窗口在相交月份可查看，显示完整课堂汇总；月度积分仍按原始时间独立计算。

## 自动识别与回溯

- 新课堂从第一次记分起算固定窗口，默认120分钟，账号设置可改为5–360分钟；只影响以后新建的窗口。
- 同班窗口内操作同属课堂，结束边界不包含在内；不同班独立；新窗口遇到未来已有窗口时截断，不产生重叠。
- 题目示例中的08:10、09:10若属于同班，在显式两小时规则下会归为同一节，可拆分或调整默认窗口。
- 历史使用30分钟无记分间隔识别候选，而非用120分钟重组已核查课堂。
- 历史默认“待校正”，有证据并确认后为“已识别”；没有证据不补造课堂，允许手动补建和标“未知”。
- Qiuzizhao此前核查的99个课堂通过原流水ID、班级、小组、分值、时间逐项比对后，一次性记录历史确认审计。
- 9月8日三(1)班+5/-5仍为疑似测试、待校正；用户已确认的10月29/30测试原无有效流水，不生成教学课堂。
- 自动窗口内记录全部撤销时不显示为有效课堂；原始记录保留，仍可在同日时间轴核查。手动补建零记分课堂不会隐藏。

## 数据

新增 lesson_settings、lessons、lesson_entries、lesson_revisions。
lesson_entries.entry_id唯一，一条月度明细只归属一堂课。
monthly_score_entries增加reason和batch_id，并从尚存原流水补全；插入触发器同步保留此后所有记分元数据。
撤销仍保留月度账本原行，以voided_at标记；课堂统计只计算有效行。
有积分状态历史但缺少原流水时，以observed_only证据展示，不伪造操作类型、不计入课堂或月度净分。
全班批次完整归属；编辑、拆分、合并保存前后审计，源课堂归档，不删除积分。
创建、编辑、拆分、合并使用BEGIN IMMEDIATE；新记分和撤销更新课堂revision，旧编辑请求返回409。
所有接口按账号及班级归属校验。编辑中有新数据时提示，退出编辑刷新；其他设备通过SSE更新。

## 保护范围

不改累计、月度、奖励或已有积分归档的口径。不开发课均排行榜。
只新增课堂关系与审计；原始transactions、当前分数、奖励和旧归档不因编辑课堂而修改。
新增元数据字段不改变月度表既有字段；完整备份仍使用一致性SQLite副本。旧v5 JSON不携带课堂数据。
