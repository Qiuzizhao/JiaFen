# 加分桌面助手（Windows 试用版）

独立的置顶记分面板，使用现有 Flask 服务器的账号、接口与 SSE。网页和手机照常使用，无需部署新后端。

## 直接试用

打包后双击 `dist/JiaFen-Desktop-0.1.9.exe`，输入现有账号密码。程序自动连接 `https://jiafen.qiuzizhao.com`，登录页不再展示服务器输入框和重复说明。调试地址仍可通过 `JIAFEN_SERVER` 指定。

界面与 JiaFen 网页统一：蓝色主色、浅灰背景、白色圆角小组卡片、原有小组颜色，以及绿色加分和粉色扣分按钮；排行榜沿用网页的前三名配色。

小组卡片一行两个，默认只显示组名和分数，鼠标悬停后原位切换为 `− / +`，点击扣一分或加一分。键盘 Tab 聚焦按钮时同样展开；触屏设备直接显示按钮。

窗口宽 320 像素，高度随小组数量、当前视图和展开的操作栏自动调整，记分和排行榜最高 460 像素，超出后内容区滚动。班级切换合并到标题栏；播报详情放在播报页，记分时只保留一行开关。收起后为 210 × 44 像素悬浮条。

超过八个小组时，卡片自动切为 50 像素高的紧凑行，组名与分数并排显示，使九组可在高度上限内完整展示；悬停加减分方式不变。

排行榜使用约 28 像素高的紧凑单行列表，缩小筛选条、行间距和外框内边距，保留同分并列及前三名配色。名称过长时省略，悬停可看全名。

播报页将范围和接收班级改为紧凑行，试听、停止、账号及动态可一屏显示；详细语音说明放到悬停提示，去掉页底重复的播报状态条。

- 顶部选择教室电脑的当前班级；手机切班不会改变电脑接收班级。
- 小组 `+1 / −1`、全班 `+1`、自定义正负分值；分数先显示，保存成功后播报。失败后重新核对服务器，不自动重发。
- 撤销前展示账号最近一笔记录；包括手机发起的操作，全班记分整批撤销。
- 排行榜：全班小组、全校小组、班级总分。同分并列排名；记分按钮保持固定组序。
- 播报：当前班级全部操作 / 仅本机 / 静音。手机和电脑用同一账号，手机静音，由电脑播报。
- `−` 收成可拖动悬浮条，`×` 隐藏到托盘；两种状态都继续接收、播报。
- `Ctrl + Alt + J` 显示或隐藏；托盘右键可以停止播报或彻底退出。移动后记住位置。
- Windows 本地 TTS，需有中文语音包。断线重连只核对积分，不补播已错过的语音；电脑休眠或退出后不接收。

这一版覆盖加减分事件的远程播报，未包含手机发送任意文字、设备管理或开机自启。

## 本地开发和打包

```powershell
cd desktop
npm install
npm start
npm test
npm run dist
```

`dist` 输出 Windows x64 免安装程序和 `win-unpacked` 目录。程序配置、会话保存在系统应用数据目录，积分仍在服务器。

调试本地后端可设置 `JIAFEN_SERVER=http://127.0.0.1:5000`。`JIAFEN_DESKTOP_DATA` 可为测试指定独立配置目录。

## 验证

`npm test` 检查流式中文消息解析和请求边界。`node test/integration.cjs` 使用项目 `.venv`、本地临时数据库和 Playwright 启动真实 Electron，覆盖登录与会话、本机和手机记分、班级筛选、断线恢复、失败写入核对、收起和隐藏、排行榜、批量撤销、自定义扣分、静音及 Windows 语音队列。

集成测试需先 `python -m venv .venv` 和 `.venv/Scripts/python -m pip install -r requirements.txt`（在仓库根目录执行），并通过 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright。测试数据和截图放在已忽略的 `desktop/test-output`，不连接线上账号。

## 实现边界

- 本地页面启用 CSP、沙箱和上下文隔离；仅通过窄接口访问允许的 API，远程网页不获得 Node 权限。
- 登录会话使用独立 Chromium 持久会话；不保存密码。
- 主进程管理 SSE、重连和 Windows 语音工作进程；界面隐藏时不销毁。
- 短队列依次播报，积压超过 15 秒的内容丢弃。唯一客户端标识防止本机回推重复播报；SSE 序号和时间去重，跳号时重新核对。
- 窗口置顶、托盘、后台设置依照 [Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window/) 和 [Session](https://www.electronjs.org/docs/latest/api/session/) 官方 API 实现。
